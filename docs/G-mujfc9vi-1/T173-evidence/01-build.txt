## 3) vite build 的前置 esbuild 服务（本会话沙箱不可用）
# 3a) 原样（esbuild 以 stdio:pipe 启动长驻服务）
$ node -e "<esbuild.transformSync>"   -> esbuild FAIL spawn EPERM
# 3b) 套 sandbox-pipe-shim（pipe -> 临时文件 fd；esbuild 需要双向 stdio，不适用）
$ NODE_OPTIONS="--require sandbox-pipe-shim.cjs" node -e "<esbuild.transformSync>"   -> esbuild FAIL Cannot read properties of undefined (reading 'on')
=> 结论：vite build 依赖 esbuild 长驻服务的 stdio 管道，本会话沙箱下无法启动；构建证据到 tsc 为止。
