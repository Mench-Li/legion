## 三、★★★ 生成器**生成了语法都不合法的代码**

第一次生成出来的模块，`node --check` 直接报：

```
SyntaxError: Duplicate parameter name not allowed in this context
export function createTeamViewsRoutes({
  json,                    ← 硬编码解构的那一个
  json, db, listTasks,     ← 我写进 deps 的那一份
}) {
```

根因在 `gen-family.mjs`：`INJECT = [...F.deps, ...autoInject]` **没有去重**，
而紧挨着的注释**已经断言**「`json` 是签名里硬编码解构的，所以它**既不在 `INJECT` 里**、又确实可用」——
**代码从来没兑现过那句话**：只要 `deps` 里写了 `json`，它就会被解构两遍。

> 一个「注释说了 `json` 不在 `INJECT` 里，那它就不在」的印象，
> 与一个「那句话从来没被任何代码或判据兑现过」的事实，
> 在我往 `deps` 里写下第二个 `json` 之前是同一个东西。

★★ **更阴的一层**：同一个重复**在下面那个对象字面量里是合法 JS**（后者静默覆盖前者），
所以只有**参数表**那一处会炸 —— 万一重复发生在对象里，它会**静默通过**。

★ 修法：两处都去重，并**当场断言**没有重复名字（`dupNames` 非空即抛）。
本片同时修掉了切片 41 那处 `usedCtx`（没剥字符串字面量）。

## 五、两条路由实测出来的语义（17 例判据）

### `GET /api/roster`（编队投影）

- `scope` 缺省（或空串）= **`all`**，聚合全部空间；每个 agent 带自己的 `scope`。
- `mode` 优先级 **blocked > review > busy > idle**。
- `chips` 四种标签顺序固定：`进行中 N`(green) / `待验收 N`(yellow) / `受阻 N`(red) / `待命 N`(空)；
  **一个都没有时**回落成 `已完成 N`（有历史）或 `待命`。
- ★★ `done` 只数 `done`；**`total` 是"除 `canceled` 以外"的总数**（`done` 也算）——
  我第一版以为 `total` 数的是"未完成的"，红在自己的预期上。
- 每个 agent 只带**未完成**任务的 `{id,title,status}`。
- ★★★ **未入编队但认领了该空间任务的执行者也要返回**（`external: true`，名字带 ` · 执行中` 后缀，
  avatar `⚙️`）—— 源码注释写明是"避免切换空间后信息丢失"。

### `GET /api/overlaps`（L3 改动重叠审计）

- `min` 被 **钳到至少 2**（`min=1`/`0`/`-5`/`abc` 都等于 2）。
- ★★★ `patches` 的**三种形态**都认：旧库**纯字符串**、`files` **数组**、`files` **CSV 字符串**。
- 同一个任务在同一个文件上出现多次**只算一次**（用了 `Set`）。
- 组内按 `id` **自然序**排（`n2` 在 `n10` 前）；组间按 `updatedAt` **倒序**。
- `id=` 过滤到含该任务的组；`scope=` 过滤；**只被一个任务改过的文件不成组**。
- 组里任务带 `{id,title,status,updatedAt}`。

★ 两条都是 **GET / 只读** —— 模块里**没有任何写动作**，连 `now()` 都不取
（生成器第二道判据当场拦下了我多写的 `now`）。
