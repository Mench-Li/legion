## 一、★★★★★ 新判据量出一条真缺陷：404 的 `code` 那一格是**空的**

`GET /api/team-plan` 缺席时回 404，里面写着：

```js
json(res, 404, {
  ok: false,
  code: CONTEXT_PLAN_ERRORS.TEAM_PLAN_NOT_FOUND,
  error: …,
  serverTimeMs: Date.now(),
})
```

★ 而 `CONTEXT_PLAN_ERRORS` 的键**只有这七个**：

```
PLAN_NOT_FOUND / PLAN_INVALID / PLAN_FROZEN / MANIFEST_NOT_FOUND /
MANIFEST_INVALID / PLAINTEXT_SECRET / SCOPE_UNKNOWN
```

★★★ **没有 `TEAM_PLAN_NOT_FOUND` 这个键。** 于是那一格取出来是 `undefined`，
而 `JSON.stringify` 会把 undefined 的字段**整个丢掉** ——
**404 响应里根本没有 `code`**。

> 一个「404 里带着 `code: 'TEAM_PLAN_NOT_FOUND'`，装配器照着它把缺席翻成
> 「有原因的 `missing`」」的印象，
> 与一个「那个对象上从来没有这个键，于是这一格是**空的**」的事实，
> 在我把 `CONTEXT_PLAN_ERRORS` 的键逐个列出来之前是同一个东西。

**影响面正好是这一族存在的理由。** 段首注释把它写得很清楚：

> 缺席一律 **404**（不是 200 带 null）：装配器把 404 翻成 `null`，
> 再由 `sources.mjs` 产出一条**带原因**的 `missing` 候选。

★ 现在**机器可判的那一格不见了**，只剩人读的文案。

★ **已核对是搬之前就有的**：`git show e9ae706:team-hub/server.mjs` 里那一行与搬进模块的
**逐字相同** ⇒ 本片只是把它**原样**搬了过来（对拍要求如此），**没有顺手改**。
§「本片没有做」里记为第 20 条钉住未修的缺陷。

## 五、★★★ 我的抹字器有一处**内层反引号**的假红

`check-free-identifiers.mjs` 本片报出：

```
✖ team-plan-read.mjs       未绑定：
        L107: $
```

★★ 那一行是**逐字从 `server.mjs` 搬过来的、对拍通过的**代码：

```js
? `空间 ${scope} 里没有团队计划 ${askId}${version === null ? '' : ` 的第 ${version} 版`}`
```

★ 抹字器的旧写法是"见到 `` ` `` 就一路吞到**下一个** `` ` ``"——
对单层模板没错，但这一行里**还嵌了一层模板**，于是它在**内层**反引号处提前收尾，
把 `` 的第 ${version} 版` `` 当成**代码**来扫，`${` 左边的 `$` 通过了标识符正则。

> 一个「`$` 被报成自由标识符，一定是生成器把哪个名字漏了」的印象，
> 与一个「它是我这个抹字器的**内层反引号**没认出来」的事实，
> 在我把那行逐字打出来看之前是同一个东西。

★ **这条假红不能靠"多报一个无所谓"糊过去**：它出现的那个模块本来是全绿的，
而"合计 0"是这道判据**唯一**的读数 —— 一条假红会让那个读数失去意义。

★★ 修法：按**栈**扫。进模板记一层；模板里遇 `${` 转**代码态**（那里的名字是**真引用**，
必须扫）；代码态按花括号深度配平后回到模板态；`` ` `` 只在模板态收尾。
★ 并写了 `probe-blank47.mjs` 做双向自测：既验"嵌套模板不再漏 `$`"，
也验"**修得不过头**"（`${scope}`/`${askId}`/`${version}` 的真引用都还在、`$foo` 这种合法标识符原样保留）。
⇒ 45 个模块，未绑定名字合计 **0**。

## 六、钉住的语义（16 例判据）

- ★★★ `scope` 必填 —— 缺 / 空白都 400 `MISSING_PARAM`；★ 校验顺序是**先 scope 后 version**。
- ★★★ `version` 必须是 **>= 1 的整数**，否则 400 `BAD_VERSION`；★ 空白按"没给"处理。
- ★★★ **缺席一律 404，绝不是 200 带 null** —— 且 404 里**不带 `plan` 字段**、
  `ok` 为 `false`、带 `serverTimeMs`（且必须是**刚刚**）。
- ★★★ 404 的**文案说清是哪一种缺席**：`没有团队计划 <id>` vs `没有挂在目标 <goalId> 下的团队计划`
  （两种缺法的**修复动作不同**）；带 `version` 时文案里出现「的第 N 版」，不带时不出现。
- ★★★ 只给 `id` ⇒ 取**最新版**；给了 `version` ⇒ 取**那一版**（哪怕有更新的）；
  按 `goalId` ⇒ **必须取最新版**；`id` 优先于 `goalId`。
- ★★ 跨空间隔离：空间 A 读到 A 的、B 读到 B 的、C 读到 404。
