# T-088 S6 测试 · L2 浏览器交互验收「环境受限」记录（R-18，不冒充通过）

## 现象
本沙箱（workspace-write、禁网、无审批通道）拒绝 Chrome/Edge 启动：
  chrome.exe --headless=new --no-sandbox ... --remote-debugging-port=9231
  -> mojo\public\cpp\platform\platform_channel.cc:108  Check failed: . : 拒绝访问。(0x5)
    （crashpad 亦 OpenProcess 拒绝访问后 self-terminating）
根因：Chromium Windows 的 mojo IPC 需创建命名管道（CreateNamedPipe），与沙箱「禁止打开命名管道 /
Node 子进程 pipe-stdio spawn -> EPERM」为同一文件沙箱边界（R-18；工具文档明示）。试过 --single-process、
--disable-crash-reporter、--enable-features=PlatformChannelUsesWindowsSocket 等均无法绕过；
机器上另无 Firefox/Brave。=> 真实浏览器 GUI 走查在本会话不可行。
