# BUG-030｜节点侧那 5 个模块：探针说"可达"，而它们在**生产上**可能从未被拉起

> 状态：**仅登记（未修）** —— 需要一次**部署侧的核对**，不是代码改动。
> 发现：2026-10-12，收尾修 `reachability` 的既有红时，给探针补了两个漏扫点
> （`desktop/` 进扫描面、`product/node/entry.mjs` 进 `PROCESS_ENTRIES`）。
> 补完之后 24 条从"不可达"变成"可达"——其中 5 条的正确性**取决于一个未核实的前提**。
> 影响面：`product/node/{entry,agent,egress,executor,ledger}.mjs`、
> `packages/shared/src/ws-client.mjs`；核对处：部署清单 / systemd / 打包清单。

## 0. 一句话

那 5 条现在的"可达"**完全建立在"`product/node/entry.mjs` 是一个真实入口"之上**，
而支撑它的证据**只有研发工作树里的路径**。

## 1. 证据（两面都列出来，不藏另一面）

**支持"它是入口"的那一面**（所以我把它登记进 `PROCESS_ENTRIES`）：

```
product/server/verify-domain.sh:32      后台起它
product/server/verify-final.sh:40       同上
product/server/smoke.sh:30              按路径跑
product/server/verify-experience.sh:17  同上
product/server/README.md:155-158        「⑤ 电脑配对」把这一步写成命令
```

**不支持"它在生产上真的跑"的那一面**（所以这里存疑）：

- 那些 `.sh` 里写的是 **`.claude/worktrees/legion-remote-agent/…`** —— 一个**研发工作树**的路径。
  在一台部署机器上，那个目录**不存在**；
- **没有 systemd 单元**（对照：`product/server/backup.mjs`、`offsite.mjs` 都有
  `legion-hub-*.service` 的 `ExecStart` —— 那种证据才叫"生产上被拉起"）；
- **不在打包清单**里（对照：`desktop/scripts/shell-files.mjs` 逐字列了随发布物的壳文件）；
- `product/process-manifest.mjs` 里**没有它**（那份清单是"哪些进程该被服务托管"的权威）。

## 2. 为什么要单独记一条，而不是"补上入口就完事"

我补入口这个动作**是对的**：探针漏扫一个入口会把正在跑的东西报成死代码，
而那正是这个探针最忌讳的失败（它自己的文件头写着这条）。
但补偿完之后的读数会**看起来比事实更好**：

> 一个"我把它登记成入口，于是它可达了"的读数，
> 与一个"它真的被生产拉起来了"的读数，
> 在探针的汇总里是同一个东西——**而只有后者是部署事实**。

所以这一条的意义是：**那个 by-design/可达 的结论有一个前提，而前提没被核实过。**

## 3. 核对清单（三步，都能给出是/否）

1. 在**部署机**上：`ls <部署根>/product/node/entry.mjs` —— 文件在不在？
2. `systemctl list-units | grep -i legion` 与 `product/process-manifest.mjs` ——
   有没有任何东西按**部署路径**（不是工作树路径）起它？
3. 若都没有 ⇒ 那 5 条应当改判 `gap`，并按 §5 的同类先例决定：
   **接上它**（写 systemd 单元 / 进 process-manifest）还是**删掉它**（连同 `ws-client`）。

## 4. 另一处同类存疑（一并记，不必开两条）

`product/update/index.mjs` 那条 barrel：现在它随 `desktop/` 一起可达，但它的唯一
importer 是 `product/update/modules.test.mjs:100`（**用例**）。
⇒ "barrel 有没有生产消费者"与"那一族模块有没有生产消费者"是**两个问题**：
前者现在答"没有"，后者答"有（经 `desktop/update-wiring.mjs`）"。
之所以不单开一条：它是同一批补扫描的产物，且结论只是一个**读法**上的提醒。

## 5. 判断句

> 一条"我给它登记了入口，于是它可达了"的记录，
> 与一条"它真的被生产拉起来了"的记录，
> 在**探针的汇总**里长得一样 ——
> 而它们分别回答的是"我漏没漏看"与"它在不在跑"这两个不同的问题。
