# BUG-034｜"它会自己补上的默认值"被当成了差异，于是那扇门依旧开着不了

> 状态：**已修**（2026-10-12）
> 影响面：`services-plugin/materialize-plan.mjs`（两侧模型的比较语义）
> 判据：`services-plugin/shadow-materialize.test.mjs` ③c（三条，两个方向都钉）

## 0. 一句话

Legion 侧**没声明** `input`（归一化成 `null`）、而 DSH 侧因为引擎的默认值报了
`input: ['text']` —— 比较把这一对当成差异。**而写进去也不改变任何东西**
（物化不带 `input`，DSH 照样落 `defaultInput`）⇒ 它唯一的后果是
**每 5 分钟重写一次、永不收敛**，而门禁的放行条件恰恰是"连续几轮 diff 为空"。

## 1. 因果链（读 DSH 源码得出，不是猜）

```
svea-ds 的 patch 里模型没声明 input
  ⇒ packages/llm/llm-pi-ai/src/config.ts：modelFields.input **没有默认值**
     （注释原话："No explicit default… schemastery materializes `[]` for an absent array,
      and resolution reads that as 'no answer here' so the catalog entry below still applies."）
  ⇒ 解析回落到路线级 defaultInput = DEFAULT_INPUT = ['text']（config.ts:80/336/454）
  ⇒ adapter.ts:276-287 `listModels()` **总是**报 `inputModalities: [...model.input]`
  ⇒ dsh-snapshot 把 inputModalities 收成 `input` ⇒ 快照带上 `['text']`
  ⇒ Legion 侧没有 ⇒ `normalizeInput(undefined)` = `null`
  ⇒ null ≠ ['text'] ⇒ **永久报一处差异**
```

对照锚（为什么 `fjd-ds` 是干净的）：它的 patch **显式**声明了 `input: [text, image]`，
Legion 侧也有同一份 ⇒ 两侧表态相同 ⇒ 不算差异。
**⇒ 差异只出现在"DSH 补了默认值、而 Legion 没表态"的那一格上。**

## 2. 修法与口径

`materialize-plan.mjs` 新增 `modelDiffers()`：**Legion 侧为 `null`（未声明）的字段不参与比较**。

这与 `provider-store` 的更新语义是**同一条**：**留空即继承，不覆盖**。
用户没在 Legion 里声明 `input`，不等于"他要一个没有输入能力的模型"——
那只是"他没表态，让它继承引擎的默认"。

  > 一处"它会自己补上"的默认值，与一处"它真的不一样"的差异，
  > 在 `models` 这一格上是同一行；
  > 而前者永远消不掉 —— 于是那道门永远开不了。

⚠ **两个值必须可分辨**，否则这条规则会吞掉真实意图：

| Legion 侧 | 归一化结果 | 判定 |
| --- | --- | --- |
| 没声明 `input` | `null` | **不比较**（继承引擎默认） |
| 显式 `input: []` | `[]` | **仍然是差异**（"我要清空它"是表态） |
| `input: ['text']` vs `['image']` | 两侧非 null 且不同 | **仍然是差异** |

判据 ③c 把这三个方向都钉住了。

## 3. 顺带消掉一个**分叉隐患**（正是 BUG-033 的形态）

修之前，"未变"用指纹（`fingerprint`）判定，而"改了哪个字段"用 `changedFields`
**另算一遍** —— 同一个事实写在两处。这次的改动如果在其中一处漏掉，
就会出现"报未变、同时又报 `models` 变了"这种自相矛盾的读数。

⇒ 现在两者**共用** `sameAs()` / `modelsEqual()`。判据 ③c 里那条反向锚
（`changedFields(...)` 必须返回 `[]`）就是为了钉住"不会分叉"。

  > 一处被实现两遍的判定，与一处被判定的语义，
  > 只在有人改其中一处的那天分叉 —— 而那天的症状是**读数自相矛盾**，
  > 不是报错。

## 4. 修复后的预测与实测

用真实数据（Legion 走中枢 API、DSH 侧按 patch 声明 + 默认值规则复现）先算了一遍：

```
counts = {"create":0,"update":0,"delete":0,"unchanged":2}
clean  = true
engineInternal = ["deepseek-account","deepseek-official"]
```

```
供应商影子对账：新增 0 / 修改 0 / 删除 0 / 未变 2（clean=true）；
**不接管**（端点由引擎内置、Legion 读不到，**任何东西都不许写它们**）：deepseek-account, deepseek-official
```
