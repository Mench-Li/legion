# Legion 协作台：原型实现

开发分支：`codex/legion-interface`。本工作区从原仓库已有改动建立基线，再独立开发，未合并回原仓库。

## 界面与仓库功能映射

- 主导航：总览、Agent、任务、资源、动态；设置固定在底部。原有功能通过二级导航保留。
- Agent：按真实空间分组，展示岗位、任务工作状态；点击注册岗位进入对应独立对话，任务详情可直接联系 Agent。外部执行者沿用仓库规则，仅查看任务。
- 任务：保留现有六列状态和任务详情，二级导航提供任务筛选。
- 资源：文件中心、技能中心、规范。
- 动态：通知、实时动态、上下文快照。
- 设置：空间管理、持续执行、工作流、模型与凭证、连接与令牌、浏览器助手。

## 对话实现

在既有 conversations/message/awaiting/reply 接口上增加空间与岗位绑定。同一个空间岗位复用唯一会话，历史空间讨论保持独立。服务端核验岗位注册状态，运行守护使用对应岗位模型和任务上下文回答。任务上下文不构成真实执行结果。草稿和滚动位置按空间岗位分别保存。

## 隔离预览

在工作区根目录运行：

```powershell
node workbench/scripts/interface-preview.mjs --source-data D:/project/DSH/legion/team-hub/team.db
```

实际源数据库位置请以原仓库配置为准。预览复制允许列表中的空间、岗位、任务等业务数据到本工作区 `.interface-preview`，不复制凭证、聊天消息或运行记录，不启动运行守护。前端端口 4821，中枢端口 8791。已有预览数据库会复用。

预览：`http://127.0.0.1:4821/?api=http://127.0.0.1:4821`。

## 模型设置修正（2026-10-02）

统一模型配置卡片、输入框、下拉菜单为浅色高对比度样式。新增默认显示的「供应商与模型」页签，通过本机 DSH 的 Remote 接口读取供应商目录、全局配置、实际模型目录与默认模型。新增/编辑供应商支持 API 地址、协议、模型 ID 和只写 API 密钥；可通过 DSH 获取可用模型。岗位分配使用实时模型目录，旧的静态候选不再参与本页选择。

DSH 供应商配置是全局配置，独立预览只在用户点击保存时写入该 DSH；预览测试不改真实 DSH 配置。桥接限定本机 3080 端口和模型相关 Remote 方法，保留 DSH 登录鉴权；配置写入携带读取时的 revision，逐字段修改并保留现有模型能力字段。API 密钥不写入 localStorage 或 Legion 数据库。

真实 DSH 接口当前返回 401，需先用 DSH 启动时提供的链接登录，再刷新本页。现阶段仅验证真实接口的鉴权失败提示，保存与目录获取流程用接口模拟数据验证，未宣称真实供应商配置保存成功。

相关测试：桥接与模型设置状态测试 62 项通过；原有模型 API 行为测试 14 项通过。完整 model-api.test.mjs 另有 1 项既有失败：旧平台路由提取未覆盖部分工作流、仓库与任务接口。本次未改动这些 hub 路径，已比较修改前后的字面量路由集合一致。浏览器验收涵盖配色、供应商表单、版本号、凭证写入、模型元数据保留、实时模型目录及窄屏布局。
