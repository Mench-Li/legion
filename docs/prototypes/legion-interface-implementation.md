# Legion 协作台：原型实现

开发分支：`codex/legion-interface`。本工作区从原仓库已有改动建立基线，再独立开发，未合并回原仓库。

## 界面与仓库功能映射

- 主导航：总览、Agent、任务、资源、动态；设置固定在底部。原有功能通过二级导航保留。
- Agent：按真实空间分组，展示岗位、任务工作状态；点击注册岗位进入对应独立对话，任务详情可直接联系 Agent。外部执行者沿用仓库规则，仅查看任务。
- 任务：保留现有六列状态和任务详情，二级导航提供任务筛选。
- 资源：文件中心、技能中心、规范。
- 动态：通知、实时动态、上下文快照。
- 设置：空间管理、持续执行、工作流、模型与凭证、连接与令牌、浏览器助手。

## 对话实现

在既有 conversations/message/awaiting/reply 接口上增加空间与岗位绑定。同一个空间岗位复用唯一会话，历史空间讨论保持独立。服务端核验岗位注册状态，运行守护使用对应岗位模型和任务上下文回答。任务上下文不构成真实执行结果。草稿和滚动位置按空间岗位分别保存。

## 隔离预览

在工作区根目录运行：

```powershell
node workbench/scripts/interface-preview.mjs --source-data D:/project/DSH/legion/team-hub/team.db
```

实际源数据库位置请以原仓库配置为准。预览复制允许列表中的空间、岗位、任务等业务数据到本工作区 `.interface-preview`，不复制凭证、聊天消息或运行记录，不启动运行守护。前端端口 4821，中枢端口 8791。已有预览数据库会复用。

预览：`http://127.0.0.1:4821/?api=http://127.0.0.1:4821`。
