## 1 数据服务与接口

- [ ] 建立稳定岗位 Agent 身份，与现有 roster 同步；绑定 direct/task 会话，重复创建幂等。
- [ ] 建立独立消息路由、用户请求去重、只读进度查询和可选模型解释路径；进展不触发旧助手。
- [ ] 建立反馈、结构化问题、决策、命令、汇报和已读仓储；服务端验证 scope、目标、版本和来源。
- [ ] 注册 API，沿用当前写令牌与 by 的本地可信客户端边界，明确共享令牌模式不提供独立用户鉴权。
- [ ] 验证跨空间访问、重复发送、同键不同载荷、并发会话创建和旧聊天兼容。

## 2 真实进展与可靠投影

- [ ] 从持久化 Attempt、RunEvent、结果和任务验收记录生成模板汇报，保存事件引用。
- [ ] 实现持久补偿、报告唯一键、事务消息投影和一般事件节流；失败和阻塞及时可见。
- [ ] 与中枢运行写入/定时对账接线，复用公开 audit SSE；重启、重复事件与离线恢复不重复消息。
- [ ] 验证生命周期稀疏时只报告已知事实，Run 完成与任务完成分别展示。

## 3 反馈与阻塞问答

- [ ] 追加要求事务保存并回执下一轮生效；有效反馈可跨重试保留。
- [ ] 接入生产上下文装配，精确记录被 snapshot 纳入的反馈，排除预算未纳入项。
- [ ] 问题回答使用版本条件更新，保留旧评论路径，拒绝迟到或重复决策。
- [ ] 验证运行中反馈不改变冻结输入，回答可由后续执行消费。

## 4 执行控制

- [ ] 新命令使用具体任务和 Attempt 身份，持久 hold 阻止再认领。
- [ ] Orchestrator 消费控制命令，通过 Runtime Contract 取消；只有已确认终态结算成功。
- [ ] 旧命令失效、不取消新 Run；未知结果不得重跑。停止后重跑使用新 Attempt 和新快照。
- [ ] 验证状态并发、hold 所有权、取消失败和进程退出恢复。

## 5 Workbench 入口

- [ ] 将智能体任务面板扩展为对话、任务、产物、规则与技能、运行记录入口。
- [ ] 嵌入 Agent 对话，显示多任务目标、依据、反馈生效和命令回执。
- [ ] 复用 SSE/补读，正确处理空间切换、未读和上翻历史，能力不足时明确说明。
- [ ] 接入任务详情到 Agent 会话入口，保持现有 3D 场景与工作流配置接口。

## 6 验证和交付

- [ ] 运行新增仓储、HTTP、Worker、上下文与事件恢复测试，以及受影响的已有套件。
- [ ] 构建 Workbench 和相关插件；登记新增套件并执行仓库门禁。
- [ ] 对一次性数据库运行真实 HTTP 闭环；探测真实 Runtime 可用性，记录可验证范围。
- [ ] 更新设计实施状态、操作说明和验证结果，提交在本分支，不自动合并或修改主工作区。

## 完成判据

用户能点击 Agent 进入持续会话，在执行时查询真实状态，收到有证据的进展，追加要求并查看生效回执，回答问题并发起有回执的停止或重跑。刷新和后台重启保留历史。Unsupported 能力、失败、UnknownOutcome 和待验收均真实展示。模块存在但未被生产调用不算完成。
