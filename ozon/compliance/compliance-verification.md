## 1. 任务 1 — Ozon 刀具类目准入结论

### 1.1 官方 API 直接信号（ozon_category_tree，A 级，优先采信）

| 搜索词 | description_category_id | type_id | type_name | **disabled** | 判定 |
|---|---|---|---|---|---|
| Подставка для ножей（刀架） | 17027907 | 92397 | Подставка для ножей | **false** | 类目/类型未禁用 → 可建品 |
| Точилка для ножей, ножниц（磨刀器） | 17027907 | 94462 | Точилка для ножей, ножниц | **false** | 类目/类型未禁用 → 可建品 |

- 两个目标 type_id（92397 刀架、94462 磨刀器）返回 **`disabled=false`**，即 Ozon 官方 API **未禁止**在该类目/类型建品。这是任务指定的官方直接信号，结论采信为「可上架」。

### 1.2 类目结构佐证（配件类目独立于「刀具」类目，A 级）

对俄语词「Ножи」检索类目树，返回的「刀具」相关节点与目标 SKU 分属不同 category：

| 节点 | description_category_id | 说明 | disabled |
|---|---|---|---|
| Ножи кухонные（厨房刀具） | 17027921 | 刀具本体类目 | false |
| Ножи, топоры, лопаты（刀/斧/铲） | 17029008 | 刀具/冷兵器大类 | false |
| Ножи электрические（电动刀） | 17039641 | 电动刀具 | false |
| **Подставка для ножей / Точилка（目标 SKU）** | **17027907** | **厨房配件类目（非刀具本体）** | false |

- 关键事实：刀架与磨刀器的 type 归属 `description_category_id=17027907`（厨房配件类目），**与「Ножи кухонные」(17027921) 刀具类目相互独立**。二者是「刀具的附属/配套件」，非刃本体。

### 1.3 外部口径（中文 + 俄语，D 级，佐证而非替代官方信号）

- Ozon 对「刀具/冷兵器」确有跨境限制传闻（中文卖家问「Ozon 跨境店不可以销售刀具么」）；Ozon 自 2025-10 起强化违禁品管控（售违禁品终止合同）。[D] https://www.073980.com/question/78559.html 、 https://www.yilantop.com/news/103365 、 https://erp.91miaoshou.com/blog/article_3099.html
- Ozon 禁售/限售清单中，「刀具」指向**刃具/冷兵器（холодное оружие、нож）**，未将「刀架/磨刀器」这类无刃配件单列为禁售。[D] https://zhuanlan.zhihu.com/p/687251429 、 https://www.amz123.com/guide/ozon/x4HkDGla
- 跨境店新限制（2025-06-26 起）覆盖电子产品、汽车摩配、DIY 工具等类目，未涉及厨房刀架/手动磨刀器。[D] https://www.100ec.cn/index/detail--6640003.html （引用自搜索结果）、 https://www.ikjzd.com/articles/1808761878554542082

### 1.4 结论（逐 SKU）

| SKU | 结论 | 依据（来源） | 置信度 |
|---|---|---|---|
| SKU-5 磁吸刀架（不附刀） | **可上架**（受限程度低） | 官方 API `disabled=false`（92397）；配件类目 17027907 独立于刀具类目 17027921 | A，高 |
| SKU-6 手动磨刀器（非电动） | **可上架**（受限程度低） | 官方 API `disabled=false`（94462）；手动款非电动（规避 TR CU 004/020） | A，高 |

> 决策红线（维持 sku-shortlist §1.2）：刀架**不附刀本体**、磨刀器**不附电动件**；二者均**不宣称「武器/冷兵器」用途**。

## 2. 任务 2 — 6 SKU 的 HS 编码与进口关税

### 2.0 口径判定（先立规则）

- **FBO = 批量进口，按 HS 编码计征关税**，不适用 5% + 200 欧门槛的 B2C 直发口径（profit-model §1.2 #2/#2b）。故本文 6 SKU **全部按 HS 口径给税率**。
- 税率来源：IFCG（俄罗斯海关咨询）TH ВЭД 逐码查询页，第三方 B 级；以欧亚经济委员会官方 ЕТТ ЕАЭС 表复核（§4）。
- 进口 VAT：官方标准 **20%**（IFCG 页面统一标 22%，与官方 20% 冲突，本文以官方 20% 为基准、IFCG 22% 标注为来源分歧，见 §2.2）。

### 2.1 逐 SKU 关税表

|---|---|---|---|---|---|---|
| SKU-1 | 厨房/浴室清洁套装（刷×2+海绵×4+刮水刀×1） | PP/PU/橡胶 | **9603**（刷/刮水刀） | 9603 90 990 0（其他刷，12.5%）／9603 90 910 0（橡胶刮水刀，10%） | **12.5%**（以刷为套装主特征） | 中（套装按主特征归类，需报关行定） |
| SKU-2 | 家用手套（丁腈/乳胶，3–5 双） | 丁腈/乳胶 | **4015** | 4015 19 000 0（硫化橡胶其他手套） | **10%** | 高 |

### 2.2 关键说明

- **关税区间实测 3%–14%，并非均匀 10–15%**：profit-model §1.2 #2b 的「日用百货 10–15%」是货代粗口径；逐码实测显示 8205 手动工具低至 3%、4602/3924 仅 6–6.5%、7323 约 9–10%、4015 约 10%、9603 约 12.5%、6804 约 14%。→ 对利润模型是**利好修正**（多数 SKU 到岸成本乘数低于保守 1.38 假设）。
- **VAT 口径分歧（来源标注，非臆造）**：IFCG 页面统一标 `Import VAT: 22%`，与俄官方标准 20%（profit-model §1.2 #3 采 20%）冲突。本文以官方 **20%** 为基准、22% 为压力上限，与 profit-model 一致；分歧待 §3 报关行复核。
- **SKU-1 套装归类**：含刷（9603）、海绵（3926）、刮水刀（9603 90 910 0）多件，按《归类总规则》3(b) 以「刷」为主特征 → 9603 90 990 0（12.5%）；若报关行判定刮水刀为主则 10%。**待报关行定**。
- **SKU-6 磨刀器归类是唯一重大分歧**：手动拉杆式磨刀器在俄罗斯报关实务中可归 **6804 22（磨石/磨具，14%）** 或 **8205 51（家用手动工具，3%）**，二者税率差 11 个百分点，直接改变 SKU-6 到岸成本（+9% 档）。**必须以具体品名/图样由报关行预归类（待补证 #2）**。
- **SKU-2 手套 PPE 边界（关联 EAC 判定）**：IFCG 4015 19 000 0 页面标注「可能落入 TR CU 019/2011（个人防护 PPE）范围」——与 sku-shortlist §1.2 判断一致：**普通家用手套若无「防护」宣称则不属 PPE**；一旦宣称防化学/防切割即触发 PPE 强制认证。**红线：只定位家用手套，不写防护宣称。**

### 2.3 关税口径总结论（对齐 profit-model §4 #1）

- 6 SKU 在 FBO 模式下**全部按 HS 口径计征关税**（非 5% B2C 口径）。
- 逐 SKU 税率区间：**3%–14%**；其中 SKU-6（若归 8205）3%、SKU-3 6.5%、SKU-4 6%、SKU-5 9%、SKU-2 10%、SKU-1 12.5%、SKU-6（若归 6804）14%。
- 进口 VAT 基准 20%（IFCG 标 22% 待复核）。
- 对 profit-model 的影响：到岸成本关税乘数（1+关税）落在 **1.03–1.14** 区间，**均低于**其保守情景 1.15 假设；保守乘数 1.38（15%+22% VAT 折算）偏悲观，可下调（但 VAT 仍按 20%）。

## 6. 结论边界（诚实声明收尾）

1. Ozon 类目准入的 `disabled=false` 是官方 API 信号，但**跨境/Global 主体白名单需招商书面闭环**后才算终判。
2. 关税税率采 IFCG 第三方逐码值，**须以欧亚经济委员会官方 ЕТТ ЕАЭС 表 + 报关行 DDP 方案复核**后才进入 profit-model 精确重算。
3. SKU-6 磨刀器、SKU-1 套装、SKU-5 竹木款三处的**归类与税率未终判**，标注「待补证」，不臆造。
