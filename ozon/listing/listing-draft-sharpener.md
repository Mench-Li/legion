## 3. 俄语描述（结构化）

```
Ручная двухступенчатая точилка для кухонных ножей

Назначение
Компактная ручная точилка для кухонных ножей. Восстанавливает остроту
лезвия за несколько движений — без специальных навыков и без подключения
к сети.

Материалы
Корпус выполнен из ударопрочного ABS-пластика. Первый этап — карбид
вольфрама (грубая заточка режущей кромки), второй этап — керамика
(чистовая доводка и полировка).

Особенности
• Двухступенчатая система: карбид + керамика в одном корпусе.
• Нескользящее основание и эргономичная рукоятка для надёжной фиксации.
• Полностью ручной и механический принцип работы — без батареек и проводов.
• Компактный размер: удобно хранить в кухонном ящике.
• Нож в комплект не входит.

Характеристики
• Тип: точилка для ножей, ножниц
• Количество этапов заточки: 2
• Материал корпуса: ABS-пластик
• Материал абразива: карбид, керамика
• Длина: около 20 см

Как пользоваться
1. Поставьте точилку на ровную нескользящую поверхность.
2. Вставьте лезвие в прорезь первого этапа (карбид) и проведите 3–5 раз
   от пятки к острию.
3. Повторите на втором этапе (керамика) для чистовой доводки.
4. Промойте лезвие водой и вытрите насухо.
5. Храните в сухом месте, недоступном для детей.

Обратите внимание
Точилка предназначена для ручной заточки кухонных ножей. Не подходит для
ножей с зубчатой кромкой и керамических ножей. Работает без питания.
```

> 说明：全文以正面表达「手动/机械、无需供电」代替「非电动」，规避敏感词 «электрическая»（见 §8 红线自检）。

## 6. 图片要求清单（Ozon 规范）

- **主图白底**：纯白背景（RGB 255/255/255），商品占画面 ≥50%，居中无阴影遮挡。
- **分辨率**：最小 500×500 px；**建议 1200×1200 px 或 2000×2000 px**（高清放大）。
- **格式/色彩**：JPG / PNG / WebP，sRGB 色彩空间，单张体积符合平台上限。
- **禁止**：主图不得有水印、Logo、促销文字、边框、拼图、价格标签；不得使用网络盗图。
- **多角度**：正面、侧面、45° 俯视、底部（防滑纹）各一张。
- **细节特写**：两个磨口（碳化钨槽 + 陶瓷槽）特写、手柄防滑纹理特写。
- **使用场景**：手持磨刀演示（不出现刀本体以外的危险元素；可放平放的菜刀示意，突出「磨刀器」主体）。

- **数量**：建议 4–8 张；主图 1 张 + 细节 2–3 张 + 场景/比例 1–2 张。

**理由（899 ₽）：**
1. 高于盈亏平衡 626 ₽，留约 270 ₽ 安全垫（代发级），大批价垫更厚（≈460 ₽）。
2. 卡在 **<1500 ₽** 佣金档内，享受 12% 而非 18% 佣金，避免跨档成本跳升。
3. 落在目标价带 300–900 ₽ 的**高端**（心理价 899 < 900 整数锚点）。
4. 首单若做促销/券，降价空间至 626 ₽ 盈亏平衡线仍有 ~270 ₽ 腾挪，不会击穿成本。

> 推断标注：净利基于利润模型假设（关税 6804/8205、FBO 履约 110₽、退货 5–8%），正式定价前待报关行预归类 + Ozon 实际履约费闭环（profit-model §4）。
