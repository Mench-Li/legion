## 一、我要采购的产品（详细介绍）

### 1.1 品名与形态

> **手动二段式厨房磨刀器（Handheld 2-stage knife sharpener）**

- 俗称：磨刀器 / 磨刀神器 / 二段式磨刀器
- 形态：手持式，一端一个磨口，共两个磨口（两段）
- 俄语名（上架用）：`Точилка для ножей`（刀/剪磨刀器）

### 1.2 材质结构（二段式，核心）

| 部位 | 材质 | 作用 |
|---|---|---|
| 第一段磨口（粗磨） | **碳化钨 / 钨钢（карбид вольфрама / tungsten carbide）** | 修整钝口、磨出刃形 |
| 第二段磨口（精磨） | **陶瓷（керамика / ceramic）** | 精磨、抛光刃口 |
| 外壳 | **ABS 塑料**（或其他硬质塑料） | 握持 + 固定 |
| 底部 | 防滑设计（橡胶/防滑纹） | 磨刀时稳 |

### 1.3 尺寸与重量（**待实测，下单前必须问清**）

| 项 | 目标值 | 说明 |
|---|---|---|
| 长度 | 约 **20 cm** | 与上架标题一致 |
| 净重 | 约 **200 g**（0.2 kg） | 上架 `weight` + 头程运费核算依据 |
| 宽/高 | 待实测（约 5–6 cm） | 上架 `width/height/depth` |

### 1.4 功能与使用

- 纯**手动**、**机械**磨刀，**不用电、无电池、无电线**；
- 两步完成：刀在粗磨口拉 3–5 下 → 陶瓷口精磨收尾；
- 适用：厨房菜刀、水果刀（**不适用**：锯齿刀、陶瓷刀）。

### 1.5 红线（必须逐条满足，缺一不采）

| # | 红线 | 原因 |
|---|---|---|
| 1 | **不含刀片/刀具本体** | 刀具本体属 Ozon 独立受限类目，磨刀器不附刀 |
| 2 | **纯手动、非电动** | 电动款归入不同类目/资质要求 |
| 3 | 无「防护/武器/食品级」宣传 | 合规红线，避免拒审/下架 |

## 二、产品关注点（采购前必问，逐条打勾）

| 关注点 | 为什么重要 | 目标答案 | 风险 |
|---|---|---|---|
| ① **磨口材质** | 决定「钨钢+陶瓷二段式」是否成立 | 第一段钨钢(碳化钨)+第二段陶瓷 | 页面只标「合金钢」，实为单材质的坑 |
| ② **段数** | 二段式是 SKU-6 定义 | 2 段（粗磨+精磨） | 买到单段款，货不对版 |
| ③ **外壳材质** | 上架属性「材质」要填 | ABS 塑料 | 影响属性值/合规 |
| ④ **尺寸长宽高** | 上架 `dimensions` + 头程运费 | 实测 mm | 占位数据导致运费算错 |
| ⑤ **净重** | 上架 `weight` + 头程运费 | 实测 g | 同上 |
| ⑥ **是否含刀** | 红线 1 | 不含刀 | 含刀＝跨类目风险 |
| ⑦ **电动/手动** | 红线 2 | 纯手动机械 | 电动款错类目 |
| ⑧ **颜色款式** | 主图要白底可拍 | 黑色/白色单色优先 | 花哨背景难做白底图 |
| ⑨ **包装** | 出口俄罗斯 | 中性/英文包装，无中文 | 中文包装需换标 |
| ⑩ **起订/价格阶梯** | 一件代发→批量 | 1 件起 + 批发价 | 只能大批起订，样品难采 |
| ⑪ **运费** | 成本核算 | 义乌发国内/国际小包运费 | 隐性成本 |
| ⑫ **出口资质** | 报关（HS 6804/8205） | 能提供报关资料 | 卡出口 |

## 三、沟通话术（中文，直接复制发微信/旺旺）

### 3.1 开场 + 询价（通用模板）

```
你好！我在为俄罗斯市场（Ozon 自营）采购厨房磨刀器，看到贵店这款磨刀器，想了解一下，方便的话请回复。

我要的规格是：手动二段式磨刀器——第一段钨钢（碳化钨）粗磨、第二段陶瓷精磨，ABS 塑料外壳，长度约 20cm，纯手动不带电、不含刀片。

请问：
1. 你们这款 2 档的，两段磨口分别是什么材质（是不是钨钢+陶瓷）？
2. 尺寸（长宽高）和净重是多少？
3. 批发价 / 一件代发价分别多少？起订量多少？
4. 是否支持先买 1–2 件样品？
```

### 3.2 规格确认（关键，逐条发）

```
麻烦帮我逐条确认下这款的关键规格，我要对客户负责，谢谢：

1. 磨口材质：第一段是不是碳化钨（钨钢）？第二段是不是陶瓷？还是两段都是合金钢？
2. 外壳：ABS 塑料吗？有没有防滑设计？
3. 尺寸：长 × 宽 × 高各多少毫米？净重多少克？
4. 是否包含刀片/刀具？还是只有磨刀器本体？
5. 纯手动机械的吧？不用电、没有电池电线？
6. 颜色有哪几种？能拍白底图吗？
```

### 3.3 样品单下单

```
我先采购 2 件样品（1 件验货 + 1 件留样拍照），走一件代发可以吗？

样品费 + 运费（到 [收货地址]）总共多少？怎么付款、什么时候发货？
麻烦发货前帮我拍照确认：两个磨口（钨钢口和陶瓷口）细节 + 整体尺寸。
```

### 3.4 批量 / 一件代发 / OEM（后续，样品 OK 后再发）

```
样品确认没问题的话，我后续会批量采购（俄罗斯 Ozon 自营 FBO），量会逐步起来。想问下：

1. 阶梯价：比如 100 / 500 / 1000 件的单价分别是多少？
2. 支持贴牌（OEM）或中性无标吗？
3. 支持一件代发吗？代发小包运费怎么算？
4. 能不能配合出报关资料？
```

### 3.5 出口俄罗斯（重点）

```
这批货要出口到俄罗斯，需要确认：
1. 包装能否做中性英文包装（避免中文字样）？
2. 能不能提供产品材质说明，方便报关预归类（大概 HS 6804 或 8205）？
3. 有没有出口到俄罗斯的经验？头程（铁路/空运）你们能协助吗？
```
