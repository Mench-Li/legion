让一支 Agent 编队替你交付

你以将军身份发布目标，而不是逐个派任务：目标自动拆成阶段任务链， 交给这个空间专属的编队执行，过程、补丁、测试证据与验收记录统一沉淀回任务。 而代码、终端与凭证，始终留在你自己的机器上。

你发布目标，不是派任务

大多数工具要你写一条条指令。Legion 要你说清"要什么"，然后由编队把它拆开、分工、执行、 验证，并把每一步的凭据留在任务上——你只负责验收。

🎯

目标自动拆成任务链

发布一个目标，它被拆成阶段任务，按依赖依次流转；每次流转都由状态机管着，可追溯、可暂停、可取消。

👥

编队各司其职

每个空间有自己的岗位编队。软件流水线默认八个岗位，从需求澄清一路走到部署与 CI/CD。

🔒

代码留在你自己的机器上

本地优先：仓库、终端、构建工具与模型凭证都在你的电脑，Hub 只做身份、路由与记录。

📎

过程与证据沉淀回任务

补丁、diff、测试输出、产物与验收记录都挂在同一条任务上，验收不离开浏览器。

需求分析师方案研究员任务拆解师测试设计师 编码工程师代码审查员测试执行员部署运维员

软件流水线的默认编队。编队是一份可打包、可移植的工件，你也可以定义自己的岗位与阶段。

三层，各安其位

Hub 不必跑代码、不必跑大模型；你的电脑从内网主动连出来，不需要在路由器上开任何入站端口。

手机

查看与指挥

看谁在线、谁在忙、谁卡住；和 Agent 对话、发布目标、审批高风险动作。可安装到主屏。

Hub

随时在线的中枢

身份、任务路由、对话与进展事件、在线状态与通知。是任务和协作记录的权威来源。

你的电脑

真正干活的地方

仓库、终端、构建与测试、本地模型都在这儿。电脑离线时任务排队，不会替它读你的工作区。

下载电脑版

桌面端把 Hub、工作台与执行节点装成一体，装完即可在手机上连上它。

三步开始

从下载到第一支编队跑起来。

装桌面版

下载并安装，桌面端会拉起本地的 Hub 与工作台。首次启动会引导你建立空间。

手机连上它

在手机上打开 /mobile/，装上主屏；电脑版与手机端共用同一套账号。

发布第一个目标

在指挥台写清你要什么。编队接手后，进展与证据会回到任务里，你在上面验收。
