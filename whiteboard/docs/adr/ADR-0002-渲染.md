# ADR-0002 渲染

- 状态：草案（待将军签发）

## 决策

Canvas 2D 单画布（形状 + 笔迹统一渲染）+ 独立透明 presence overlay +
Renderer 接口解耦（apps/web/public/js/renderer.mjs）。命中检测为标准几何计算
（packages/shared/hitTest.mjs），与渲染层解耦，可独立单测。

## 理由

- 7/8 主张：单画布对 1000/5000 元素最省 DOM 开销，帧率稳定。
- Renderer 接口使 S6/S7/S8 不感知具体实现，未来可换 SVG 混合而不改上层。
- 文本以 Canvas fillText 纯文本渲染，天然不执行 HTML（XSS 门禁 FR-11）。

## 被否方案

- SVG(形状)+Canvas2D(笔迹)+overlay 三层（coder 原主张）：多一层 DOM 管理，
  命中改 DOM 层序，5000 元素下 DOM 开销更高，v1 收益不明显。

## 代价

- Canvas 无 DOM 语义，文本选中/复制等需后续自实现（v2 富文本再议）。
