# ADR-0003 v1 元素与操作清单

- 状态：草案（待将军签发）

## 决策

v1 元素：rect / ellipse / line(含箭头) / freehand / 单行纯文本（text）。
v1 操作：单选 / 移动 / 元素缩放 / 删除 / 改色 / 线宽 + 无限画布 pan/zoom
（视口变换，不入文档）。

v2 明确排除：多选、图片、旋转、编组、橡皮擦、压感、富文本、账号体系、
多实例横向扩展、完全离线编辑、多房间、导入导出、深色主题。

## 理由

- 全票收敛：覆盖「图形元素」原始诉求的最小完备集。
- 字段契约见 packages/shared/src/schema.mjs（validateElement）。

## 被否方案

- 一步到位支持 v2 清单：范围失控，单实例/单进程先跑通再扩展。

## 代价

- 无多选/编组，复杂绘图场景受限；由 v2 承接。
