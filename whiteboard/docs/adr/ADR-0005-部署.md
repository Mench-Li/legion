# ADR-0005 部署形态

- 状态：草案（待将军签发）

## 决策

单容器 Docker（多阶段构建）+ docker-compose + 静态前端（零构建，直接托管）+
单进程 Node（http + 自研 ws relay + /healthz）。v1 显式声明单实例、不承诺横向扩展。

## 理由

- 单进程承载 relay + 状态 + 持久化，50 并发 soak 已验证可用（见 bench）。
- /healthz 探活含存储可读性（isHealthy）。
- 静态前端无需 Vite/打包（禁网环境无依赖可用），server 直接托管。

## 被否方案

- 多实例横向扩展 + 外部数据库：v2 范围，v1 不承诺。

## 代价

- 单实例 = 单点；压力上限以 50 并发 soak 为界，超限明确转 v2。
