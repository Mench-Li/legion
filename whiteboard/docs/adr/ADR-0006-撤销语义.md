# ADR-0006 撤销语义

- 状态：草案（待将军签发）

## 决策

每用户局部撤销（仅撤本人操作，origin/clientId 隔离，绝不撤销他人 op）。
redo 语义 = clear-on-remote（6/8 默认）：撤销后一旦远端并发 op 落进本人历史作用域
→ 本地 redo 栈清空。undo 深度 ≥100（实现上限 1000）。

实现：packages/shared/src/undo.mjs，undo/redo 以更高 Lamport 时钟重放逆/正 op，
既隔离他人 op，又保持 CRDT 收敛（undo 结果同样同步到远端）。

## 理由

- 局部撤销对齐 Y.UndoManager origin 过滤；协作撤销明确排除 v1。
- clear-on-remote 避免「redo 重放把并发 op 的状态又盖回去」的语义歧义。

## 被否方案

- keep-replay（breaker/coder 原主张）：保留 redo、仅重放本人 op；已作备选分支保留。
- 全局/协作撤销：v1 明确排除。

## 代价

- 撤销与并发编辑同一字段时，以 LWW 为准（undo 重放可能覆盖后来的他人字段值），
  这是「每用户局部撤销 + LWW」的固有边界，已文档化。
