# ADR-0007 状态分层

- 状态：草案（待将军签发）

## 决策

持久态（图形元素，进 undo/持久化）与临态（协同光标/在线列表，走 awareness
独立通道）物理分离。presence 绝不入文档、绝不进 undo 历史、绝不进持久化。

实现：presence 只存在于服务端 Room.presence 聚合 + ws 广播（type=presence/leave），
文档 CRDT 与存储 op 日志不含任何 presence 字段（门禁断言见 room.test.mjs TC-S4-06）。

## 理由

- 光标高频（20Hz）与文档低频（手势级）生命周期不同，混入文档会污染 undo 与持久化。

## 被否方案

- presence 入文档：undo 会撤销他人光标、持久化体积膨胀，违反 NFR-6。

## 代价

- 两条通道需分别处理断线清理（presence TTL）与状态同步（快照回放）。
